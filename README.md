# WeTV Clone

A modern streaming platform UI clone built with React and Tailwind CSS.

## Features

- 🎬 Beautiful banner slider with 5 slides
- 📱 Responsive design
- ✨ Smooth animations and transitions
- 🎨 Modern gradient designs
- 📺 Two main pages (Home & Channel)

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Install Tailwind CSS:
   ```bash
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   ```
4. Start the development server:
   ```bash
   npm start
   ```

## Technologies Used

- React 18
- Tailwind CSS
- JavaScript ES6+

## Project Structure

```
src/
├── components/
│   └── WeTV.jsx - Main component
├── App.js - App wrapper
└── index.css - Global styles with Tailwind
```

## Usage

Navigate between pages using the top navigation bar. The banner slider automatically changes every 5 seconds, or use the navigation arrows and indicators.

Enjoy! 🎉
